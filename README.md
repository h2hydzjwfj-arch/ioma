# Безопасный логистический калькулятор

Это переработанная версия: список агентов вынесен на сервер, вход защищён, ставки сохраняются на сервере, пользовательские значения экранируются.

## Запуск
1. Установить Node.js 18+.
2. Выполнить `npm install`.
3. Сгенерировать хеш пароля:
   `node tools/create-password-hash.js "123UU789gt*rt"`
4. Скопировать `.env.example` в `.env` и указать `ADMIN_PASSWORD_HASH` из шага 3 и длинный случайный `SESSION_SECRET`.
5. Запустить `npm start`.
6. Открыть `http://localhost:3000`.

Важно: для реального интернета использовать HTTPS (reverse proxy вроде nginx/Caddy), firewall и не публиковать `.env`.

## Что защищено
- пароль не хранится в JavaScript и не отправляется клиенту;
- scrypt для хеша пароля;
- HttpOnly + SameSite cookie;
- подпись сессии HMAC;
- ограничение попыток входа;
- Helmet/CSP и защитные HTTP-заголовки;
- ограничение JSON body;
- серверная проверка ID агента и размера ставки;
- экранирование данных перед выводом в HTML;
- `rel=noopener noreferrer` для внешних ссылок;
- атомарная запись ставок.

Никакой веб-сайт нельзя честно гарантировать как «невзламываемый». Перед публичным запуском нужен HTTPS, обновления Node/npm и регулярный аудит.
